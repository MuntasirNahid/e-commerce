# E-Commerce Platform

This project is an **e-commerce platform** designed and developed as part of our **CSE 3/1 Web Development Project**. It incorporates features for **banking transactions**, **supplier management**, **consumer functionality**, and **admin control**. The project was collaboratively created by **Muntasir Mamun** and **Kabid Hasan**.

## Features

### **Consumer Features:**
- Browse and search for products.
- Add products to the shopping cart.
- Place orders and process payments via integrated banking transactions.

### **Supplier Features:**
- Manage inventory.
- Add, update, and remove products.
- View and fulfill orders.

### **Admin Features:**
- Oversee platform operations.
- Manage users (consumers and suppliers).
- Analyze sales and transaction reports.

### **Banking Transactions:**
- Secure and reliable payment processing integrated within the platform.

## Installation and Setup

### **Prerequisites:**
- **Node.js** (v14 or later)
- **PostgreSQL** (v12 or later)
- **npm** or **yarn** for dependency management

### **Steps to Run Locally:**

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/MuntasirNahid/e-commerce.git
   cd e-commerce
   ```

2. **Setup Backend:**
   - Navigate to the backend directory:
     ```bash
     cd backend
     ```
   - Install dependencies:
     ```bash
     npm install
     ```
   - Configure the database connection in `config.js` or `.env` file.
   - Start the backend server:
     ```bash
     npm start
     ```

3. **Setup Frontend:**
   - Navigate to the frontend directory:
     ```bash
     cd ../frontend
     ```
   - Install dependencies:
     ```bash
     npm install
     ```
   - Start the frontend development server:
     ```bash
     npm start
     ```

4. **Access the Application:**
   - Open your browser and navigate to `http://localhost:3000`.

## Usage

1. **Consumers:**
   - Sign up and log in.
   - Browse products and place orders.

2. **Suppliers:**
   - Log in to manage inventory and fulfill orders.

3. **Admins:**
   - Monitor platform activity and manage users and transactions.
